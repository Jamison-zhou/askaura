# 象问品牌应用原型

这是一个独立的品牌落地 Demo，不会修改正式首页或业务逻辑。

本页以确认后的 D 版“双界折线路径”标志为母版，包含：

- 标准主标志与中英文字标；
- 桌面 / 移动导航组合；
- 边界出现、路径穿越、节点点亮的加载动画；
- 卡背与章节封面应用；
- 160px 至 20px 的尺寸检查；
- 深夜、浅色和单色版本。

启动项目静态服务后访问：

`http://127.0.0.1:5174/prototypes/brand-system/`

快捷键：

- `1`–`5`：切换应用场景；
- `D` / `M`：切换桌面或移动预览；
- `R`：重播加载动画。
