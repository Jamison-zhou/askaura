## 单张结果的精修提示词

当某张方向基本正确但还不够精致时，把生成结果作为最新参考图上传，并复制下面这段；只替换方括号中的内容：

```text
请在保持上一张作品的世界观、主构图、5:8 比例和核心意象不变的前提下，做一次精修重绘。

只调整以下内容：
1. [例如：主体轮廓再清楚 15%，缩略图更易识别]
2. [例如：减少背景雾气和无意义颗粒]
3. [例如：旧铜线更细、更克制，红色节点缩小 20%]
4. [例如：底部 18% 进一步压暗并减少细节]

保持不变：墨黑与深海蓝的大面积底色、骨白主光、单一珊瑚红节点、哑光纸纤维和轻微旧金属质感、安静理性的电影感、主体安全区。

仍然不要生成任何中文、英文、编号、Logo、水印或卡框；不要新增星座、符文、水晶、法阵、宗教标记；不要改变成常规奇幻海报或霓虹科幻风格。
```
