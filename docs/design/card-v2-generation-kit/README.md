# AskAura 卡牌 V2 图像生成包

这套材料用于让 ChatGPT 先生成 6 张代表性牌面，验证整套卡牌的新视觉系统。当前阶段不覆盖网站中的正式图片，也不一次重画全部 22 张。

## 推荐方向

**夜航叙事 70% + 观测站结构 30%**

- 保留 AskAura 的深夜、海面、远山、旧金属、骨白和珊瑚红节点。
- 增强游戏卡牌的收藏感、辨识度和场景叙事。
- 每张牌只保留一个清晰主意象，小尺寸时也能分辨。
- 不采用传统占卜图案、法阵、星座、符文、水晶或泛用神秘人物。
- 生成图只做“插画层”，中文名、英文名、编号、边框和状态效果统一由网页叠加。

## 为什么先做 6 张

这 6 张覆盖了最容易暴露系统问题的类型：

1. `愚者`：人物与旅程起点
2. `女祭司`：静态人物与双界结构
3. `恋人`：双人物与关系选择
4. `死神`：强烈转折，但不能依赖陈旧视觉套路
5. `高塔`：建筑与事件冲击
6. `太阳`：明亮牌，但仍要属于深夜世界观

确认这 6 张后，再把相同规则扩展到其余 16 张，可以避免整套返工。

## 在 ChatGPT 中怎么用

1. 新建一个对话，上传公共参考图 `01`、`02`、`03`、`04`。
2. 如果先看整体方向，复制 `prompts.md` 中的“快速方向板提示词”。
3. 如果生成单张样卡，再上传该牌对应的旧图，并复制对应的单张提示词。
4. 每次只生成一张单牌原图，不要让模型把 6 张牌排在同一张生产图里。
5. 下载原图，文件名先使用 `-candidate-a`，不要覆盖网站现有资源。

## 交付规格

- 画布：竖版 `5:8`，推荐 `1280 × 2048`；模型不能精确输出时，至少保持严格的 5:8 构图。
- 输出：无文字、无编号、无 Logo、无水印、无卡框的纯插画层。
- 安全区：主体距离四边至少 7%。
- 标题区：底部约 18% 保持安静、偏暗，方便网页叠加牌名与编号。
- 缩略图：缩小到约 96px 高时，仍能认出该牌的唯一主意象。

建议候选文件名：

```text
00-the-fool-candidate-a.webp
02-the-high-priestess-candidate-a.webp
06-the-lovers-candidate-a.webp
13-death-candidate-a.webp
16-the-tower-candidate-a.webp
19-the-sun-candidate-a.webp
```

## 这轮验收重点

- 六张缩小后能否一眼区分。
- 是否仍然属于同一个“夜海观测世界”。
- 是否比现有卡牌更像高级游戏收藏品，而不是同一张海报换人物。
- 红色节点是否只作为视线焦点，而不是大面积装饰。
- 画面是否给网页文字和状态动效留下空间。
