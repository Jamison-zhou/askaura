# 塔罗结果四段式设计

## 目标

塔罗已经有“问题校准”，但结果仍然只有一句行动建议，容易显得泛。此设计把塔罗结果改成四段短笺，让用户先看到问题张力，再得到行动。

## 展示结构

塔罗结果页展示：

1. 你真正问的事
2. 这张牌照见的张力
3. 今天的判断
4. 一件小行动

前三段保持短句，最后一段沿用现有大字行动建议的视觉重心。

## 输出契约

`reading` 模式改为要求：

```text
[CORE_QUESTION]
[TENSION]
[JUDGMENT]
[ACTION]
```

梅花 `meihua-reading` 和当下 `anchor` 不改。

## 非目标

- 不新增数据库字段。
- 不改梅花和当下结果页。
- 不做多牌阵。
- 不把结果写成长文。
