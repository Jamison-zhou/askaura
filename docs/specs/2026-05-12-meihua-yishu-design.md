## 1. 梅花易数是什么（你的产品里它要做什么）

梅花易数是宋代邵雍（康节）创立的**中国本土占卜术**。和塔罗不同：

| 维度 | 塔罗 | 梅花易数 |
|---|---|---|
| 工具 | 22 张大阿尔卡那（卡牌） | 八卦（阴阳爻线组合） |
| 起占方式 | 随机抽牌 | 起卦（时间数 / 字数 / 随机数 → 推算） |
| 输出 | 1 张牌 + 正逆位 | 主卦 / 互卦 / 变卦（三卦联读） |
| 文化语境 | 西方神秘学 | 中国《易经》体系 |

**在此镜里的产品定位**（继承 PRODUCT.md "梅花与塔罗平权"原则）：
- 与塔罗**视觉、交互、流程平权**——不能"塔罗主菜 + 梅花配菜"
- 但具体表现要忠于其**东方术数**本性：不是抽牌、是起卦

---

## 2. Feature Summary

用户在 mode 选择页选「梅花易数」→ 写下问题 → **起卦**（系统按时间+用户问题字数自动起卦，或用户主动输入 3 个数字起卦）→ 显示**主卦**（六爻图 + 卦名）→ LLM 解读（核心 + 三个角度 + 行动）→ 行动收尾，配「愿」印。

与塔罗流程几乎相同，关键差异：
- 抽牌动画 → **起卦动画**
- 卡牌 PNG → **六爻 SVG**（动态生成）
- 解读 prompt 用《易经》语境（而非西方塔罗）

---

## 3. Design Direction（视觉 / 文风）

继承 PRODUCT.md + DESIGN.md。梅花易数特定决策：

- **卦象 SVG**：6 条横线，阳爻 `▬▬▬` 实心，阴爻 `▬ ▬` 中断。**纯 CSS / SVG 绘制**，颜色用 paper / paper-soft（不要朱砂——朱砂留给印章和点睛）
- **卦名 typography**：现代仿宋 SemiBold，72-96px（与塔罗"此镜"主标对齐字号梯度）。卦名两字（如"乾"、"坤"）必须居中、字距 0.30em
- **不用爻辞原文**：原文文言对 Z 世代过门槛；解读由 LLM 用现代中文输出，但**可以引用一句关键爻辞**作为锚定（"九五，飞龙在天"等）
- **解读语气** 继承 PRODUCT.md："不预测、不下定论、克制、文学化、行动收尾"

---

## 4. Scope（v1 实施范围 — 决策点）

### Option A — 最简版（推荐 v1，~3-4h）

- 起卦方式：时间数自动起卦（用户进入"起卦页"即根据当前时间生成）+ 用户输入字数补充
- 输出：**仅主卦**（不算互卦 / 变卦）
- 解读：1 个 LLM mode（meihua-reading），结构和塔罗 reading 相似（CORE / 3 ANGLES / TAKEAWAY）
- 卦象 UI：纯 CSS/SVG 渲染六爻

### Option B — 中级版（~5-6h）

A 全部 +
- 主卦 + 互卦 + 变卦（三卦联读）
- 用户可手动起卦（输入 3 个数字）
- LLM 解读区分三卦各自含义 + 综合行动

### Option C — 完整版（~7-9h）

B 全部 +
- 动爻分析（哪一爻变了 / 用动爻爻辞）
- 多个 LLM mode（含"指引卦"用于二次抽取）
- 配套**易经原文引用** UI（hover 显示爻辞）

**推荐：** Option A，保证"梅花和塔罗平权"的核心目标，避免功能过载。

## 5. Layout Strategy

继承塔罗 4 步流程（mode-select → intent → entry → reading）。梅花特定屏幕：

### 5.1 mode-select（已存在，UI 改）
- 当前梅花卡片是"Coming Soon"禁用状态——改为可点击进入

### 5.2 intent-select（复用塔罗的 看清 / 看关系 / 安定 三选项？还是另起？）
- **决策点**：是否给梅花单独设计 3 个 intent，还是复用塔罗的
- 默认建议：**复用塔罗的 3 个 intent**（看清 / 看关系 / 安定），简化用户认知

### 5.3 intent-entry（同塔罗，用户输入问题）

### 5.4 起卦页（新设计）—— 替代塔罗的 pre-stage 抽牌
- 中央显示一段"屏息默念问题"提示
- 自动倒计时 3 秒（或用户点击"起卦"按钮）
- 起卦动画：6 条横线从下往上**逐一出现**，每条线随机选阳/阴（带瞬间不确定感）
- 动画时长 ~2s，结束停在主卦上
- 配文："得 **乾** 卦" / "得 **坎** 卦"等

### 5.5 reading 页（与塔罗类似）
- 顶部：卦象 SVG + 卦名（大字）
- 下方：LLM 解读区，结构同塔罗 reading（CORE / HOOK / 3 ANGLES / TAKEAWAY）
- 行动收尾，"愿"印

## 6. Key States

| 状态 | 处理 |
|---|---|
| 起卦中 | 6 条横线从下往上逐一出现动画 (~2s) |
| 解读 loading | 同塔罗 SSE 流式 |
| Error | "起卦未完成，请重试"（不要"算命失败"等词） |
| 选定动爻（仅 Option B/C） | 朱砂方块标记变爻位置 |

---

## 7. Interaction Model

- 起卦：自动（默认）或用户点 "起卦" 按钮触发
- 卦名 hover (desktop) / tap (mobile)：弹出该卦在《易经》中的**简短卦辞**（如乾："元，亨，利，贞"）—— v1 Option A 不做
- 解读流式同塔罗

## 8. Content Requirements

### 8.1 新增后端 prompt：meihua-reading

```
[SYSTEM] {style 同塔罗}
[USER]
得卦：{gua_name}（{gua_chinese_name}）
意图：{intent}
来问：{question}
卦象：{爻线序列，如"上九 上六 九五 六四 九三 初九"}

请按以下格式输出（严格遵守）：

[CORE]
（三个 anchor 词 · 中文 1-2 字一个）然后空一行写一句 30 字以内的核心。

[HOOK]
一句 20 字以内的引子，引出下面三个角度。

[ANGLE1_TITLE] 角度一的小标题（4-6 字）
[ANGLE1_BODY] 60-100 字。结合卦象本身的象（如"乾为天"）。

[ANGLE2_TITLE] 角度二的小标题
[ANGLE2_BODY] 60-100 字。结合用户问题。

[ANGLE3_TITLE] 角度三的小标题
[ANGLE3_BODY] 60-100 字。给一个角度看现状。

[TAKEAWAY]
一句 40 字以内的话，告诉她现在可以做什么。
```

### 8.2 i18n 新增

- mode.meihua.title → "梅花易数"（已有）
- mode.meihua.subtext → "八卦 · 借象数自省"（已有）
- meihua.preStage.copy → "屏息默念你的问题"
- meihua.gua.{乾,坤,震,巽,坎,离,艮,兑}：卦名 + 一句卦辞参考
- meihua.gotGua → "得 {gua_name} 卦"

### 8.3 卦象数据

新增 `meihua_gua.json` 或在 supabase functions 内嵌：

```json
[
  {"id": "qian", "name": "乾", "binary": "111111", "image": "天", "essence": "刚健"},
  {"id": "kun",  "name": "坤", "binary": "000000", "image": "地", "essence": "柔顺"},
  ...
]
```

仅 8 卦（非 64 卦——v1 Option A 不组合上下卦）。或 v1 直接展示 8 个三爻基础卦。
